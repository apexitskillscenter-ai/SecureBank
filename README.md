# APEX IT Skills Center Website

A responsive multi-page website built with HTML5, CSS3 and vanilla JavaScript.

## Files
- `index.html` — Home
- `about.html` — About the institute
- `courses.html` — Course listings
- `instructors.html` — Instructor / academic leadership
- `admissions.html` — Admission enquiry form
- `gallery.html` — Gallery placeholders
- `contact.html` — Contact details
- `assets/css/style.css` — Shared responsive styles
- `assets/js/main.js` — Navigation, reveal effects and WhatsApp enquiry form

## Run locally
Open `index.html` in a browser. No build tools are required.

## Publish on Hostinger
1. Extract the ZIP file.
2. Open Hostinger hPanel → Websites → Manage → File Manager.
3. Open the website's `public_html` folder.
4. Upload all files and folders from this project (not the ZIP itself).
5. Make sure `index.html` is directly inside `public_html`.
6. Visit your domain and test all navigation links and the WhatsApp form.

## Important before publishing
- Replace the gallery placeholders with real, authorized institute photos.
- Confirm the contact details, course list, fees, schedules and instructor profile.
- The admission form opens WhatsApp with the entered information. It does not store submissions in a database. A backend is needed for database storage.
- Update SEO descriptions and add real social links as needed.

## Technologies
HTML5, CSS3, vanilla JavaScript. Google Fonts are loaded online; the site still works with fallback fonts if unavailable.
